Features

为看片而设计，不是为聊天

保留 Telegram 的账号与内容，重新组织成影视 App 的浏览方式：分区、筛选、收藏、队列、下载。

扫码 / 手机号登录

扫码或手机号 + 验证码登录，支持两步验证；TDLib 会话只落在应用私有目录，不经过任何中转服务器。

影视库式浏览

频道、群组、私聊分类，最近/名称排序；视频海报网格、聊天内搜索、#标签筛选，不再是瀑布流聊天记录。

边下边播

NextPlayer 播放核心，TDLib 流式字节窗口；起播不用等整段下载完，拖动进度会重新定向下载。

后台下载

WorkManager 前台任务，通知栏进度，最多 2 个并发；暂停 / 恢复 / 删除，完成后可直接离线播放。

收藏与队列

收藏整个频道/群组或单条视频；播放队列按当前筛选结果串起来，播完自动下一个。

现代 Android 适配

edge-to-edge、predictive back、手机底栏 / 平板与 TV 侧栏、动态取色、16 KB page 对齐，arm64 单 ABI。

Architecture

干净分层，数据只走本机

Compose UI → ViewModel → Repository → TDLib；播放器独立于数据层，下载由 WorkManager 托管。没有自建服务器，没有中转流量。

Kotlin 2.4Compose + M3TDLibMedia3NextPlayer 核心WorkManagerR8arm64
